# Project Summary

This project implements a basic pulse oximeter prototype using Arduino UNO, MAX30100, and a 16x2 I2C LCD.

## Goal

The goal of the project is to design and build a simple embedded system that measures and displays:

- Heart rate
- Blood oxygen saturation (SpO2)

## Core Idea

The MAX30100 module contains red and infrared LEDs, a photodetector, and analog signal processing circuitry. It estimates physiological values based on changes in light absorption through tissue.

The Arduino reads the processed sensor data and displays it on an LCD.

## Portfolio Relevance

This project demonstrates:

- Embedded programming
- Sensor interfacing
- I2C communication
- Biomedical instrumentation basics
- Arduino prototyping
- Hardware/software integration
